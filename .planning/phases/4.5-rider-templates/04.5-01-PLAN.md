## Migration 026 schema

```sql
-- +goose Up

CREATE TABLE IF NOT EXISTS rider_templates (
    id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name         TEXT NOT NULL,
    technical    TEXT NOT NULL DEFAULT '',
    hospitality  TEXT NOT NULL DEFAULT '',
    backline     TEXT NOT NULL DEFAULT '',
    other_notes  TEXT NOT NULL DEFAULT '',
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at   TIMESTAMPTZ
);

CREATE INDEX IF NOT EXISTS rider_templates_alive_idx
    ON rider_templates (name) WHERE deleted_at IS NULL;

CREATE TABLE IF NOT EXISTS rider_attachments (
    id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    gig_id       UUID NOT NULL,
    template_id  UUID,
    technical    TEXT NOT NULL DEFAULT '',
    hospitality  TEXT NOT NULL DEFAULT '',
    backline     TEXT NOT NULL DEFAULT '',
    other_notes  TEXT NOT NULL DEFAULT '',
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at   TIMESTAMPTZ,
    CONSTRAINT rider_attachments_gig_id_fkey FOREIGN KEY (gig_id)
        REFERENCES gigs (id) ON DELETE RESTRICT,
    CONSTRAINT rider_attachments_template_id_fkey FOREIGN KEY (template_id)
        REFERENCES rider_templates (id) ON DELETE SET NULL
);

-- One live attachment per gig (partial unique index — boolean pattern, NOT a subquery)
CREATE UNIQUE INDEX IF NOT EXISTS rider_attachments_one_per_gig
    ON rider_attachments (gig_id) WHERE deleted_at IS NULL;

CREATE INDEX IF NOT EXISTS rider_attachments_gig_idx
    ON rider_attachments (gig_id);

-- +goose Down
DROP TABLE IF EXISTS rider_attachments;
DROP TABLE IF EXISTS rider_templates;
```

**Design notes:**

- `template_id` is nullable — a per-gig copy may exist without a source template (matches RIDER-02 "user can select").
- `ON DELETE RESTRICT` on `gig_id` mirrors the conservative gig delete behavior; `ON DELETE SET NULL` on `template_id` keeps per-gig copies alive when the source template is deleted.
- Partial unique index uses the boolean-column pattern (not a subquery in the predicate) — Postgres-safe; follows `references/finance-module-pattern.md`.

## Model types (`rider/model.go`)

```go
package rider

import (
    "context"
    "errors"
    "time"

    "github.com/google/uuid"
)

var (
    ErrNotFound     = errors.New("rider record not found")
    ErrConflict     = errors.New("rider attachment already exists for this gig")
    ErrInvalidInput = errors.New("invalid rider input")
)

// RiderTemplate is a reusable four-section rider.
type RiderTemplate struct {
    ID           uuid.UUID
    Name         string
    Technical    string
    Hospitality  string
    Backline     string
    OtherNotes   string
    CreatedAt    time.Time
    UpdatedAt    time.Time
    DeletedAt    *time.Time
}

// RiderAttachment is a per-gig copy of a rider template (or manually entered).
type RiderAttachment struct {
    ID          uuid.UUID
    GigID       uuid.UUID
    TemplateID  *uuid.UUID
    Technical   string
    Hospitality string
    Backline    string
    OtherNotes  string
    CreatedAt   time.Time
    UpdatedAt   time.Time
    DeletedAt   *time.Time
}

// RiderSectionValues is the editable field set for either kind of record.
type RiderSectionValues struct {
    Technical   string
    Hospitality string
    Backline    string
    OtherNotes  string
}

// CreateTemplateInput is the request shape for creating a template.
type CreateTemplateInput struct {
    Name string
    RiderSectionValues
}

// UpdateTemplateInput supports partial field updates.
type UpdateTemplateInput struct {
    Name *string
    *RiderSectionValues  // nil → leave all four alone
}

// CreateAttachmentInput includes an optional template ID; when present,
// the template's current field values are copied into the new row.
type CreateAttachmentInput struct {
    GigID uuid.UUID
    TemplateID *uuid.UUID   // nil → blank copy
    RiderSectionValues
}

// UpdateAttachmentInput supports partial field overrides.
type UpdateAttachmentInput struct {
    *RiderSectionValues
}

// RepoIface is the contract the service layer consumes.
type RepoIface interface {
    // Templates
    ListTemplates(ctx context.Context) ([]*RiderTemplate, error)
    GetTemplate(ctx context.Context, id uuid.UUID) (*RiderTemplate, error)
    CreateTemplate(ctx context.Context, in CreateTemplateInput) (*RiderTemplate, error)
    UpdateTemplate(ctx context.Context, id uuid.UUID, in UpdateTemplateInput) (*RiderTemplate, error)
    SoftDeleteTemplate(ctx context.Context, id uuid.UUID) error

    // Attachments
    GetAttachmentByGig(ctx context.Context, gigID uuid.UUID) (*RiderAttachment, error)
    GetAttachment(ctx context.Context, id uuid.UUID) (*RiderAttachment, error)
    CreateAttachment(ctx context.Context, in CreateAttachmentInput) (*RiderAttachment, error)
    UpdateAttachment(ctx context.Context, id uuid.UUID, in UpdateAttachmentInput) (*RiderAttachment, error)
    SoftDeleteAttachment(ctx context.Context, id uuid.UUID) error
}
```

## Repository implementation (`rider/repository.go`)

`Repository` is the concrete `pgxpool.Pool`-backed implementation of `RepoIface`. All read paths filter `WHERE deleted_at IS NULL`; soft-delete sets `deleted_at = now()`. `CreateAttachment` checks the partial unique index and returns `ErrConflict` on a duplicate (matches `gig.ErrConflict`).

Methods:

- `ListTemplates` — `ORDER BY name COLLATE "C" ASC` (case-insensitive locale sort can come later)
- `GetTemplate` / `GetAttachment` / `GetAttachmentByGig` — return `nil, ErrNotFound` on no rows (use `errors.Is(err, pgx.ErrNoRows)`)
- `CreateTemplate` / `CreateAttachment` — `RETURNING *` to keep round-trips down
- `UpdateTemplate` / `UpdateAttachment` — coalesce nil pointers; the partial `*RiderSectionValues` is checked for nil first, then each string is treated as "update or leave" via `COALESCE($N, <column>)` pattern. EPK used a `CASE WHEN $N` pattern; either works. Use coalesce for clarity.
- `SoftDeleteTemplate` / `SoftDeleteAttachment` — `UPDATE … SET deleted_at = now() WHERE id = $1 AND deleted_at IS NULL`; if `RowsAffected == 0` return `ErrNotFound`. **Idempotent** — calling soft-delete twice returns `ErrNotFound` the second time.

`CreateAttachment` race: even with the partial unique index, two concurrent inserts both succeed-then-fail in the index check. Catch `23505` (`unique_violation`) SQLSTATE and return `ErrConflict`.

```go
import "github.com/jackc/pgx/v5/pgconn"

if pgErr, ok := err.(*pgconn.PgError); ok && pgErr.Code == "23505" {
    return nil, ErrConflict
}
```

This is the standard Postgres pattern; **document it inline with a comment** explaining why we translate SQLSTATE rather than racing the application check.

## Repository tests (`rider/repository_test.go`)

Contract tests using a hand-written `fakeRiderRepo`. No DB, no testcontainers — matches the EPK `repository_test.go` pattern (Phase 03 `[Phase 03-epk-press-kit-builder]: EPK unit tests use hand-written mockRepo (interface-substitution) — no testcontainers, no pgxmock` decision in STATE.md).

Test cases:

| Test | Asserts |
|------|---------|
| `ListTemplates_excludes_soft_deleted` | Soft-deleted template does not appear |
| `GetTemplate_returns_NotFound_for_missing_id` | `errors.Is(err, ErrNotFound)` |
| `GetTemplate_returns_NotFound_for_soft_deleted` | Same, after `SoftDeleteTemplate` |
| `CreateTemplate_then_Get_round_trips_fields` | All four sections + name preserved |
| `UpdateTemplate_partial_only_updates_named_fields` | Empty `RiderSectionValues` is a no-op for sections |
| `UpdateTemplate_can_rename` | Name field updates independently |
| `SoftDeleteTemplate_then_Get_NotFound` | Soft-deleted template is invisible to reads |
| `SoftDeleteTemplate_idempotent_returns_NotFound_on_second_call` | Second call returns ErrNotFound |
| `CreateAttachment_with_template_id_records_snapshot` | Template fields are copied at create time, not live-linked |
| `UpdateAttachment_does_not_change_template_id` | Override on attachment leaves template_id intact |
| `CreateAttachment_duplicate_gig_id_returns_Conflict` | Second attachment for same gig returns ErrConflict |
| `GetAttachmentByGig_returns_live_only` | Soft-deleted attachment not returned |
| `UpdateAttachment_then_Get_returns_new_values` | Update round-trips |

`fakeRiderRepo` keeps an in-memory map of templates + attachments. The `ErrConflict` test mutates the fake's underlying state to simulate a row that already exists (the real DB error path is covered by migration + integration testing once the API is wired).
