## Wiring in `cmd/api/main.go`

After the existing `gig.NewHandler(...)` block (around line 274), add:

```go
// 9c. Wire rider module (Phase 4.5).
riderRepo := rider.NewRepository(pool)
riderStorage := rider.NewStorageAdapter(storeClient)
riderSettingsSvc := rider.NewSettingsServiceAdapter(settingsSvc)
riderSvc := rider.NewService(riderRepo, riderStorage, riderSettingsSvc)
riderHandler := rider.NewHandler(riderSvc)
```

Pass `riderHandler.Routes()` to `apphttp.NewRouter` alongside the existing handlers.

`StorageAdapter` mirrors `epk.NewStorageAdapter` — same shape; either duplicate the small adapter file or add a generic helper. **Duplicate locally** (`api/internal/rider/storage_adapter.go`) to keep the package boundary clean.

`SettingsServiceAdapter` mirrors `epk.NewSettingsServiceAdapter` — same approach. Duplicate.

```go
// NewSettingsServiceAdapter wraps settings.Service to match rider.SettingsIface.
func NewSettingsServiceAdapter(svc settingsServiceRealIface) *settingsServiceAdapter {
    return &settingsServiceAdapter{svc: svc}
}
```

`settingsServiceRealIface` is the same subset EPK uses (`GetOrCreate` + `Update`). Could be promoted to a shared type later; for now duplicate to keep packages independent.

The `NewMux` is invoked inside the package; `riderHandler.Routes()` already returns the mux-wrapped handler, so `apphttp.NewRouter` receives a single `http.Handler` — no change to the router signature.

## Mock handlers (frontend-only dev)

When `NUXT_PUBLIC_API_BASE` is **not** set, Nitro serves `apps/dj/server/api/v1/*` instead of proxying to the Go API (per Phase 1.5.5 convention documented in STATE.md). The mock files are read by `pnpm dev` without Docker.

Each mock is a small inline JS object that stores state in a module-level variable. Reset on dev-server restart. Match the shape the real API returns.

Example — `apps/dj/server/api/v1/rider/templates/index.get.ts`:

```ts
let seed: Array<{id: string; name: string; technical: string; hospitality: string; backline: string; otherNotes: string; createdAt: string; updatedAt: string}> = [
  {id: 'tmpl-1', name: 'Standard club', technical: '2× CDJ-3000', hospitality: '4 bottles water', backline: 'DJM-A9', otherNotes: 'Arrival 2h before doors', createdAt: '...', updatedAt: '...'},
]

export default defineEventHandler(() => ({ data: seed }))
```

Each mock handler follows the same envelope (`data` or `{data: null}` for empty). The PDF mock returns a placeholder URL pointing at a `data:application/pdf;base64,...` of a small static sample so the frontend download button works without a real API.
