  <action>
Create 5 Nuxt server API routes that proxy to Go backend at localhost:8080:

apps/dj/server/api/v1/gigs/index.get.ts:
- Parse query params: status, venue, city, fee_min, fee_max, from, to
- Build query string, call $fetch(GET /api/v1/gigs?{query})
- Return JSON array of gigs

apps/dj/server/api/v1/gigs/index.post.ts:
- Read body (gig fields), call $fetch(POST /api/v1/gigs, {body: gig})
- Return created gig with 201 status

apps/dj/server/api/v1/gigs/[id].get.ts:
- Extract id from params, call $fetch(GET /api/v1/gigs/:id)
- Return gig JSON

apps/dj/server/api/v1/gigs/[id].put.ts:
- Extract id, read body (gig update fields + updated_at for optimistic concurrency)
- Call $fetch(PUT /api/v1/gigs/:id, {body})
- Return 409 on conflict (passthrough from Go backend)

apps/dj/server/api/v1/gigs/[id].delete.ts:
- Extract id, call $fetch(DELETE /api/v1/gigs/:id)
- Return 204 on success

All handlers use $fetch with proper error handling (try/catch, return appropriate status codes).
