# iCal Feed (INT-02, INT-03)
- GET /api/v1/gigs/calendar.ics returns RFC 5545 compliant VCALENDAR
- Protected by ?secret={ICAL_SECRET} query param (constant-time compare)
- Each VEVENT: UID (gig UUID), DTSTART (date + time), SUMMARY (event name or venue), LOCATION (venue, city, country), DESCRIPTION (fee + currency + promoter email if present)
- Non-cancelled gigs only

# Booking Confirmation PDF (GIG-12)
- Available only when gig status is confirmed (400 otherwise)
- Pre-populated: DJ name (from settings), venue + city, date, fee + currency, set length, tech contact name + email
- No e-signature
- Uses gofpdf (same as EPK PDF)
- Store in MinIO at gig-exports/{year}/{gig_id}.pdf; return existing if already generated
- Download via presigned URL or direct redirect

# Storage pattern (from Phase 3 EPK PDF)
storage.Client.PutObject(bucket, key, reader, size, contentType)
storage.Client.GetObject(bucket, key) → presigned URL or reader

type CalendarConfig struct {

func GenerateCalendar(ctx context.Context, gigService *GigService, config CalendarConfig) (string, error)
- Call gigService.ListGigs with filter (status != cancelled)
- Build RFC 5545 VCALENDAR string:
  BEGIN:VCALENDAR
  VERSION:2.0
  PRODID:-//KlubHub//Gig Tracker//EN
  CALSCALE:GREGORIAN
  METHOD:PUBLISH
  
  For each gig:
  BEGIN:VEVENT
  UID:{gig.ID}@klubhub
  DTSTART;TZID=Europe/Berlin:{gig.Date.Format("20060102T150405")}
  SUMMARY:{eventNameOrVenue}
  LOCATION:{venue}, {city}, {country}
  DESCRIPTION:Fee: {fee_amount} {fee_currency}\nPromoter: {promoter_email}
  END:VEVENT
  
  END:VCALENDAR

func ValidateSecret(provided, expected string) bool
- Use crypto/subtle.ConstantTimeCompare
- Return true if match, false otherwise

In api/internal/gig/handler.go, add routes:

GET /api/v1/gigs/calendar.ics
- Extract ?secret= query param
- Validate against ICAL_SECRET env var (constant-time compare)
- If invalid, return 403 Forbidden
- If valid, call gigService.GenerateCalendar() → output iCal string
- Set Content-Type: text/calendar; Content-Disposition: attachment; filename=klubhub-gigs.ics

GET /api/v1/gigs/:id/pdf
- Extract ?secret= query param, validate
- Fetch gig by ID
- If gig.Status != confirmed, return 400 Bad Request
- Call gigService.GenerateBookingPDF(gig, djName) → storage path
- Return PDF as file download (Content-Disposition: attachment) or redirect to presigned URL

In api/internal/gig/service.go, add methods:
- GenerateCalendar(ctx, config CalendarConfig) (string, error) — uses GigReader to list non-cancelled gigs
- GenerateBookingPDF(ctx, gigID UUID, djName string) (string, error) — generates or returns cached PDF path
