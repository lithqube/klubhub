<!-- API contracts Plan 02 calls. These are defined by Plan 01's handler. -->

POST /api/v1/tracklists/upload
  - multipart/form-data, field "file"
  - Response 201: { tracklist: Tracklist, tracks: Track[], warnings: ParseWarning[] }
  - Response 413: { error: "file_too_large", message: string }
  - Response 422: { error: "invalid_format"|"zero_tracks", message: string }

GET /api/v1/tracklists
  - Response 200: { tracklists: Tracklist[] }

GET /api/v1/tracklists/{id}
  - Response 200: { tracklist: Tracklist, tracks: Track[] }

PUT /api/v1/tracklists/{id}/tracks/{track_id}
  - Body: { title?: string, artist?: string, bpm?: number, musical_key?: string, album?: string, genre?: string }
  - Response 200: { track: Track }

DELETE /api/v1/tracklists/{id}
  - Response 204

GET /api/v1/settings
  - Response 200: UserSettings (djName, logoPath, defaultColors, tracklist_preferences JSONB)

PUT /api/v1/settings
  - Body: { tracklist_preferences: { preset, bg_mode, visible_fields, max_tracks } }

TypeScript interfaces (canonical — use these exactly):
```typescript
interface Tracklist {
  id: string
  title: string
  sourceFormat: string
  rawFilePath: string | null
  preset: string
  visibleFields: string[]
  bgMode: 'solid' | 'upload' | 'mosaic'
  bgValue: string | null
  maxTracks: number
  trackRangeStart: number | null
  trackRangeEnd: number | null
  createdAt: string
  updatedAt: string
}

interface Track {
  id: string
  tracklistId: string
  position: number
  title: string
  artist: string | null
  album: string | null
  genre: string | null
  bpm: number | null
  rating: number | null
  durationSecs: number | null
  musicalKey: string | null
  dateAdded: string | null
  artworkStatus: 'pending' | 'fetched' | 'placeholder' | 'manual'
  artworkUrl: string | null
}

interface ParseWarning {
  row: number
  field: string
  message: string
}
```

    LEFT COLUMN — Upload zone (step = 'upload'):
    - Use @vueuse/core useDropZone on a dropzone div; also provide a hidden file input triggered by clicking the zone

    - On valid file drop/pick: show filename + file size; enable "Parse File" button
    - On "Parse File" click: call uploadTracklist(file); show loading spinner; on success transition to step = 'review' with parsed tracks
    - On error: show error banner with the error message (file_too_large, invalid_format, zero_tracks, etc.)

    - "Confirm Tracklist" button at bottom: transitions to step = 'preview'
    - Start artwork polling in onMounted after upload success: const controller = new AbortController(); pollArtworkStatus(tracklist.id, 2000, (updated) => { tracks.value = updated }, controller.signal); stop on step change or component unmount
    - Parse warnings table below main table (collapsible): shows row number + message for each warning

    - Customization panel (collapsible accordion or always-visible sidebar):

      - Background mode: radio group (solid / upload / mosaic); solid shows a color picker input; upload shows a file picker; mosaic auto-uses cover art; on change → PUT /api/v1/settings
      - Field visibility: checklist of all fields (title, artist, bpm, key, label, time_played, set_duration, dj_name, event_name, date); on change → PUT /api/v1/settings
      - Track range selector: shows only when tracks.length > tracklist.maxTracks; two number inputs (from / to), default 1 / maxTracks
      - Logo upload: file picker for PNG; preview thumbnail; position dropdown (top-left/top-right/bottom-left/bottom-right)
