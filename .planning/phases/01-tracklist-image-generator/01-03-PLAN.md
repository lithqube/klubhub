<objective>
Build the Go cover art fetch pipeline: Spotify → Discogs → MusicBrainz/CAA fallback chain, MinIO artwork cache, and the goroutine worker pool that runs asynchronously after tracklist save. Wire the artwork service into main.go so Plan 01's fire-and-forget goroutine becomes active.

Purpose: After a tracklist is saved, each track's artwork_status progresses from 'pending' to 'fetched' (or 'placeholder') without the user waiting. The frontend polls and updates thumbnails progressively. Manual artwork overrides (artwork_source='manual') are never replaced.
Output: api/internal/artwork/ package (model, fetcher, cache, worker), tracklist service wired with artwork, main.go updated.
</objective>
