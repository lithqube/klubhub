    Update `apps/dj/nuxt.config.ts` to add `routeRules` (production proxy) and `nitro.devProxy` (dev proxy). Preserve ALL existing configuration keys unchanged.

    The production `routeRules` target MUST use `process.env.NUXT_PUBLIC_API_BASE` — not a hardcoded `localhost:8080`. In Docker, `localhost` inside the frontend container resolves to the frontend container itself, not the `api` service. `NUXT_PUBLIC_API_BASE` is set to `http://api:8080` in docker-compose.yml.

    The dev `devProxy` target is `http://localhost:8080` (Go API running directly on the developer's machine, not in Docker).

    Updated file:
    ```typescript
    import { nxViteTsPaths } from '@nx/vite/plugins/nx-tsconfig-paths.plugin';
    import { defineNuxtConfig } from 'nuxt/config';

    // https://nuxt.com/docs/api/configuration/nuxt-config
    export default defineNuxtConfig({
      workspaceDir: '../../',
      devtools: { enabled: true },
      devServer: {
        host: 'localhost',
        port: 4200,
      },
      typescript: {
        typeCheck: true,
        tsConfig: {
          extends: '../../../tsconfig.base.json',
        },
      },
      imports: {
        autoImport: true,
      },
      css: ['~/assets/css/styles.css'],
      vite: {
        plugins: [nxViteTsPaths()],
      },
      // Proxy all /api/v1/* requests to the Go backend.
      // Production: NUXT_PUBLIC_API_BASE is set to http://api:8080 in docker-compose.yml
      // Dev: nitro.devProxy below handles the same path via localhost:8080
      routeRules: {
        '/api/v1/**': {
          proxy: (process.env.NUXT_PUBLIC_API_BASE ?? 'http://localhost:8080') + '/api/v1/**',
        },
      },
      nitro: {
        devProxy: {
          '/api/v1': {
            target: 'http://localhost:8080',
            changeOrigin: true,
          },
        },
      },
    });
    ```

    NOTE: `devServer.port: 4200` is the existing dev port from the Nx scaffold — preserve it. In Docker the container exposes port 3000 (the Nitro production port).
