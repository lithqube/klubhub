<objective>
Build Spotify integration for KlubHub DJ — enable importing artist data from Spotify into EPK and using track audio features for tracklist image generation.

Purpose: Spotify is the primary music streaming platform. Integrating Spotify data enriches the press kit with verified artist info, releases, and top tracks. Tracklist images can use audio features (tempo, energy, danceability) for more dynamic generation.

Output: Spotify Go client, EPK import UI, Tracklist audio features display, REST endpoints
</objective>

<context>
# Spotify Web API Overview
- Base URL: https://api.spotify.com/v1
- Authentication: OAuth 2.0
  - Client Credentials flow for public data (artist profiles, albums, tracks)
  - Authorization Code flow for user data (not needed for our use cases)
- Rate limits: 180,000 requests per 24 hours (client credentials)
- Required env vars: SPOTIFY_CLIENT_ID, SPOTIFY_CLIENT_SECRET

# Key endpoints we'll use:

**Artist:**
- GET /artists/{id} — artist profile (name, images, genres, popularity, followers, external URLs)
- GET /artists/{id}/albums — artist's albums/singles (title, release date, label, tracks, cover art)
- GET /artists/{id}/top-tracks — top tracks by market (title, duration, popularity, preview URL, audio features)
- GET /artists/{id}/related-artists — similar artists

**Tracks:**
- GET /tracks/{id} — track details
- GET /audio-features/{id} — audio features (danceability, energy, valence, tempo, key, loudness, mode, speechiness, acousticness, instrumentalness, liveness, duration_ms)

**Search:**
- GET /search?q={query}&type=artist — search artists by name

# Data mapping to KlubHub:

**Artist → EPK:**
- Spotify images[] → EPK photos (cover art / profile images)
- Spotify genres[] → EPK tags or notes
- Spotify followers → EPK "followers" stat display
- Spotify external_urls (spotify, soundcloud sometimes) → EPK social links
- Artist popularity → EPK "popularity" stat (0-100)

**Albums → EPK:**
- Albums list → EPK "Releases" section
- Each album: title, release_date, label, cover art, track count
- Singles/EP/Album distinction from album_group

**Tracks → EPK:**
- Top tracks → EPK "Top Tracks" section
- Track name, duration, preview URL (if available)

**Audio Features → Tracklist Image Gen:**
- tempo (BPM) → color hue or pattern speed
- energy (0-1) → contrast or saturation
- danceability (0-1) → layout complexity
- valence (0-1, positivity) → color palette (warm/cool)
- key (0-11) → visual motif
- loudness (dB) → visual weight

# Authentication flow (Client Credentials):
1. POST https://accounts.spotify.com/api/token
   - grant_type=client_credentials
   - client_id, client_secret (Basic auth header)
2. Response: { access_token, expires_in (3600), token_type: "Bearer" }
3. Use access_token in Authorization: Bearer {token} header
4. Cache token, refresh when expires

# Known limitations:
- No artist biography in Spotify Web API (only available via Spotify for Artists dashboard)
- Artist images are limited (one primary image)
- Top tracks are market-specific (need market parameter, e.g., "US", "GB")
- Preview URLs are 30-second snippets, may not be available for all tracks

```go
type SpotifyArtist struct {
    ID          string           `json:"id"`
    Name        string           `json:"name"`
    Images      []SpotifyImage   `json:"images"`
    Genres      []string         `json:"genres"`
    Popularity  int              `json:"popularity"`
    Followers   SpotifyFollowers `json:"followers"`
    ExternalURLs SpotifyExternalURLs `json:"external_urls"`
    Href        string           `json:"href"`
    Type        string           `json:"type"`
}

type SpotifyImage struct {
    URL    string `json:"url"`
    Height int    `json:"height"`
    Width  int    `json:"width"`
}

type SpotifyFollowers struct {
    Href     string `json:"href"`
    Total    int64  `json:"total"`
}

type SpotifyExternalURLs struct {
    Spotify     string `json:"spotify"`
    // Other URLs may be present (soundcloud, etc.) but not guaranteed
}

type SpotifyAlbum struct {
    ID          string           `json:"id"`
    Name        string           `json:"name"`
    ReleaseDate string           `json:"release_date"`
    ReleaseDatePrecision string  `json:"release_date_precision"`
    TotalTracks int              `json:"total_tracks"`
    Label       string           `json:"label"`
    AlbumGroup  string           `json:"album_group"` // album, single, compilation, appears_on, ep
    Images      []SpotifyImage   `json:"images"`
    Href        string           `json:"href"`
    ExternalURLs SpotifyExternalURLs `json:"external_urls"`
}

type SpotifyTrack struct {
    ID           string          `json:"id"`
    Name         string          `json:"name"`
    DurationMS   int             `json:"duration_ms"`
    Explicit     bool            `json:"explicit"`
    Popularity   int             `json:"popularity"`
    PreviewURL   string          `json:"preview_url"`
    Album        SpotifyAlbum    `json:"album"`
    Artists      []SpotifyArtist `json:"artists"`
    IsPlayable   *bool           `json:"is_playable"`
}

type SpotifyAudioFeatures struct {
    Danceability float64 `json:"danceability"`
    Energy       float64 `json:"energy"`
    Valence      float64 `json:"valence"`
    Tempo        float64 `json:"tempo"`
    Key          int      `json:"key"` // 0-11
    Mode         int      `json:"mode"` // 0=minor, 1=major
    Loudness     float64  `json:"loudness"`
    Speechiness  float64  `json:"speechiness"`
    Acousticness float64  `json:"acousticness"`
    Instrumentalness float64 `json:"instrumentalness"`
    Liveness     float64  `json:"liveness"`
    DurationMS   int      `json:"duration_ms"`
    TimeSignature int     `json:"time_signature"`
}

type SpotifyToken struct {
    AccessToken string `json:"access_token"`
    ExpiresIn   int    `json:"expires_in"`
    TokenType   string `json:"token_type"`
    Scope       string `json:"scope"`
    ExpiresAt   time.Time
}
```
