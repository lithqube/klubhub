## Phase 0.5 Context from STATE.md

**Decision:** `[Phase 0.5-Garage]` — Garage (https://Garage.deuxfleurs.fr/) replaces MinIO as the S3-compatible object storage layer. Garage is open-source, actively maintained, and S3 API-compatible with the existing minio-go client — no application code changes needed. All MINIO_* env vars get S3_* equivalents with MINIO_* aliases preserved for backward compatibility.

**Key constraints:**
- Garage S3 API is compatible with minio-go client — NO application code changes
- MINIO_* aliases must be preserved for existing deployments
- Garage requires explicit region (MINIO_REGION → S3_REGION)
- Single-node mode is sufficient for development

## Storage Operations to Test

After Garage is running, these operations must work:
1. Cover art upload/cache (artwork package)
2. Tracklist image export (tracklist package)
3. EPK photo upload (epk package)
4. PDF export (epk package)
</context>

<task type="auto">
  <name>Task 1: Update docker-compose.yml with Garage</name>
  <files>docker-compose.yml</files>
  <action>
    Replace the MinIO service block with Garage:

    ```yaml
    storage:
      image: ghcr.io/deuxfleurs/garage:v1.1.0
      container_name: klubhub-storage
      ports:
        - "127.0.0.1:39000:39000"  # S3 API
        - "39001:39001"              # Admin API (internal only)
      volumes:
        - storage_data:/data
      environment:
        - GARAGE_MODE=singlenode
        - GARAGE_REGION=${S3_REGION:-eu-west-1}
        - GARAGE_ROOT_KEY=${S3_ACCESS_KEY}
        - GARAGE_ROOT_SECRET=${S3_SECRET_KEY}
      healthcheck:
        test: ["CMD", "wget", "-q", "http://localhost:39000/health"]
        interval: 10s
        timeout: 5s
        retries: 5
    ```

    Keep the service name as `storage` for Docker network compatibility.
    Remove the MINIO_ROOT_USER/MINIO_ROOT_PASSWORD healthcheck format.
    Volume `storage_data` should remain at `apps/dj/data/storage` mount point.
  </action>
  <verify>
    <automated>docker compose config --services | grep -q storage</automated>
  </verify>
  <done>Garage service replaces MinIO in docker-compose.yml, configured for single-node mode</done>
</task>
