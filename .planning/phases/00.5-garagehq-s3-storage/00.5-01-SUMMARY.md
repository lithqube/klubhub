## Decisions Made

- Garage (https://Garage.deuxfleurs.fr/) chosen over MinIO: open-source, actively maintained, S3 API-compatible with existing minio-go client
- Single-node mode sufficient for development; Garage supports cluster mode for production
- Port 39000 for S3 API (MinIO used 9000) to avoid conflict if MinIO is running elsewhere
- MINIO_* env var names kept in Go config for backward compatibility; .env.example shows MINIO_* as aliases to S3_*

None - plan executed exactly as written.

## User Setup Required

**New .env file required.** Copy `.env.example` to `.env` and set:
- `S3_ACCESS_KEY` (generate with: openssl rand -hex 32)
- `S3_SECRET_KEY` (generate with: openssl rand -hex 32)

Existing .env files with MINIO_* vars will continue to work via backward aliases, but should migrate to S3_* naming.
