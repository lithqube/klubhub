<task type="auto">
  <name>Task 1: Install shadcn-nuxt module and dependencies, create components.json and lib/utils.ts</name>
  <files>apps/dj/package.json, apps/dj/nuxt.config.ts, apps/dj/components.json, apps/dj/app/lib/utils.ts</files>
  <action>
    From workspace root, install shadcn-nuxt and its peer dependencies:
    ```
    pnpm add -F @dev/dj -D shadcn-nuxt
    pnpm add -F @dev/dj clsx tailwind-merge class-variance-authority lucide-vue-next
    ```

    Update `apps/dj/nuxt.config.ts` to add the shadcn-nuxt module:
    ```typescript
    modules: ['shadcn-nuxt'],
    shadcn: {
      prefix: '',
      componentDir: './app/components/ui',
    },
    ```
    Preserve all existing fields (vite Tailwind plugin, routeRules, nitro, etc.).

    Create `apps/dj/components.json` manually (do NOT run `npx shadcn-vue init` interactively — it requires TTY):
    ```json
    {
      "$schema": "https://shadcn-vue.com/schema.json",
      "style": "default",
      "typescript": true,
      "tailwind": {
        "config": "",
        "css": "app/assets/css/styles.css",
        "baseColor": "slate",
        "cssVariables": true
      },
      "framework": "nuxt",
      "aliases": {
        "components": "@/components",
        "utils": "@/lib/utils"
      }
    }
    ```

    Create `apps/dj/app/lib/utils.ts`:
    ```typescript
    import type { ClassValue } from 'clsx'
    import { clsx } from 'clsx'
    import { twMerge } from 'tailwind-merge'

    export function cn(...inputs: ClassValue[]) {
      return twMerge(clsx(inputs))
    }
    ```

    Run build to confirm module loads:
    ```
    pnpm nx build @dev/dj
    ```
  </action>

    Apply cyberpunk visual overrides to each installed component. Work through each file, replacing default shadcn-vue classes with cyberpunk equivalents:

    **Global rule (all components):**
    - Replace ALL `rounded-*` classes (rounded-md, rounded-lg, rounded-sm, rounded-full on non-circular elements) with `rounded-none`
    - Replace `border` / `border-border` with ghost-border utility OR remove entirely (no-line rule)
    - Replace `bg-background` with `bg-surface`, `bg-card` with `bg-surface-container`

    **Button.vue — primary variant:**
    ```
    Replace: bg-primary text-primary-foreground hover:bg-primary/90
    With:    gradient-cta text-on-primary shadow-glow-primary hover:shadow-glow-primary-strong transition-shadow duration-200
    ```
    **Button.vue — secondary variant (or outline):**
    ```
    Replace: border border-input bg-background hover:bg-accent hover:text-accent-foreground
    With:    bg-transparent ghost-border text-secondary hover:text-primary hover:luminous-threshold transition-all duration-200
    ```
    **Button.vue — destructive variant:**
    ```
    Replace: bg-destructive text-destructive-foreground hover:bg-destructive/90
    With:    bg-error-container text-error shadow-glow-error hover:shadow-glow-error transition-shadow duration-200
    ```

    **Input.vue:**
    ```
    Replace: border border-input bg-background
    With:    bg-surface-container-high border-0 border-l-2 border-transparent focus-visible:border-primary focus-visible:ring-0 text-on-surface placeholder:text-tertiary
    ```
    Remove any `rounded-md` → `rounded-none`

    **Dialog (DialogContent):**
    ```
    Replace: bg-background (content area)
    With:    glass-panel-heavy text-on-surface
    ```
    Remove border and shadow-* defaults, add `luminous-threshold`

    ```
    Replace: bg-card border shadow-sm
    With:    glass-panel (no border, no shadow-sm)
    ```
    For highlighted/active cards: add `luminous-threshold`

    Replace destructive variant: bg-destructive text-destructive-foreground border-destructive
