## Decisions Made

- **index.vue is a Dashboard, not a redirect**: The plan specified `await navigateTo('/tracklist', { replace: true })`. The actual implementation is a full Dashboard page at `/` with real widget content. This is a positive evolution — a Dashboard entry point provides better UX and was implemented in a prior phase. The redirect truth was not regressed.
- **Responsive shell pattern established**: The mobile UX uses TheMobileHeader (top brand bar) + TheBottomNav (bottom tabs) while the desktop UX uses TheNav sidebar + TheStatusBar. This dual-layout approach was added beyond the plan spec and handled cleanly at the lg breakpoint.
- **min-h-dvh over min-h-screen**: app.vue uses `min-h-dvh` to avoid the mobile-browser-chrome viewport height bug — a correct implementation detail beyond plan spec.
