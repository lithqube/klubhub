# Phase 1.5: Design System Foundation — Context

**Gathered:** 2026-03-20
**Status:** Ready for planning
**Source:** UI/UX review of Phase 1 frontend output

<domain>
## Phase Boundary

Install Tailwind CSS + shadcn-vue component library with a High-Energy Cyberpunk Editorial design language. Migrate all existing frontend code from plain scoped CSS to the design system. Decompose the two monolithic Vue files (TrackcardPreview.vue and tracklist.vue) into focused sub-components. Add Pinia for state management. Establish responsive layout, error handling, and font bundling foundations that all future phases build on.

This is a **frontend-only** phase — no Go backend changes, no database migrations, no new API endpoints.

</domain>

<decisions>
## Implementation Decisions

### Design Language: High-Energy Cyberpunk Editorial ("The Kinetic HUD")
- **Approach: Tactical HUD-inspired interface** — not a standard web template
- All surfaces follow "No-Line Rule": no 1px borders; tonal transitions and luminous thresholds only
- 0px border-radius enforced globally — aggressive and precise
- Glassmorphism on all floating panels (surface_variant at 60% opacity, backdrop-blur 20-40px)
- Depth via luminous halos (glow shadows), not grey drop shadows
- Primary + One Accent rule per screen (max 3 accent colors)

### CSS Framework: Tailwind CSS v4 via @nuxtjs/tailwindcss
- Utility-first approach eliminates scoped CSS sprawl across 8+ future modules
- Design tokens mapped in tailwind.config.ts (surface hierarchy, glows, fonts)
- Responsive breakpoints built-in (sm, md, lg, xl)
- Custom @layer components for glassmorphism utilities (glass-panel, gradient-cta, ghost-border, luminous-threshold, accent-bar-focus)

### Component Library: shadcn-vue
- Copy-paste components into `app/components/ui/` — not a node_module dependency
- Built on Radix Vue for accessibility (WCAG 2.1 AA keyboard nav, ARIA, focus management)
- All defaults overridden to cyberpunk spec post-install (gradient CTAs, glass panels, no rounded corners)
- Initial set: Button, Input, Select, Dialog, Table, Tabs, Toast, Dropdown, Card, Badge, Popover, Sheet, Separator, Avatar

### State Management: Pinia
- Three stores: settings (user preferences), tracklist (CRUD state), ui (toasts, modals, loading)
- Replaces 30+ component-local refs in tracklist.vue
- Enables cross-module data sharing for future phases (scheduler needs tracklist data, dashboard aggregates all)

### Typography: Three Font Families
- Space Grotesk (display/headlines) — "Command" font, tight letter-spacing (-0.02em)
- Inter (body) — "Data" font, clean and neutral
- Manrope (labels/metadata) — "Terminal" font, uppercase with wide letter-spacing (+0.05em)
- Noto Sans retained for image generation (CJK/Cyrillic/Arabic support)
- All bundled locally as variable woff2 — no Google Fonts CDN

### Color System: Dual Token Architecture
- **UI Theme tokens** (in tailwind.config.ts): surface hierarchy, primary cyan (#96F8FF), secondary violet (#C8B8FF), error red (#FF716C) — for the application chrome
- **Image preset tokens** (in app/utils/design-tokens.ts): 5 presets (default, dark, light, neon, minimal) — product data burned into exported images, not UI theme

### Component Decomposition
- TrackcardPreview.vue (465 lines) → 6 sub-components in `components/trackcard/`
- tracklist.vue (~50KB) → 5 feature components in `components/tracklist/`
- Naming convention: `ui/` (shadcn), `trackcard/` (image gen), `tracklist/` (feature), `The{Name}.vue` (singletons)

### Responsive Strategy
- Mobile-first with Tailwind breakpoints: <640px (single column, 48dp touch targets), 640-1024px (two-column), >1024px (side-by-side editor + preview)
- Progressive disclosure on mobile for technical metadata
- TrackcardPreview scales: 0.3 mobile, 0.5 desktop

### Claude's Discretion
- Exact shadcn-vue component override details (class replacements per component)
- CSS animation/transition details for hover states and interactive feedback
- Exact Tailwind config values for spacing, sizing beyond what's specified
- Mobile navigation pattern (Sheet slide-out vs. hamburger dropdown)
- Error boundary fallback UI layout
- Index page design (redirect vs. landing page)

</decisions>

<mockup_patterns>
## Mockup-Derived Patterns (from Google Stitch prototype, 2026-03-20)

These patterns were extracted from 4 screens (Dashboard, Tracklist/Generator, Social Scheduler, Gigs) and OVERRIDE or EXTEND the design decisions above where they conflict.

### Sidebar Navigation
- Active nav item: **dashed/dotted cyan border outline** on all 4 sides (not a solid left bar, not a filled background)
- Inactive items have a faint dashed underline only
- Logo area: "KlubHub DJ" bold white + "STATUS: SYNCED" with a green dot on the same line below
- Nav items: icon (left) + uppercase text label (right), ~280px fixed width

### Module-Level Top Navigation
- Each module (Tracklist, Social, Gigs) has its own top bar with:
  - Module title in **cyan, italic or styled font** (e.g. "KLUBHUB DJ" wordmark left + "GENERATOR" underlined tab)
  - Tab navigation with underline active indicator only (no background fill)
  - Right cluster: bell icon + settings gear + avatar
- Global top bar (Dashboard): "SYSTEM STATUS: NOMINAL" centered badge + "QUERY DATABASE..." search

### Badge / Status Pill System (concrete colors)
| Badge | Style |
|-------|-------|
| READY | cyan outline pill, no fill |
| DRAFT | violet/magenta outline pill |
| ARCHIVED | gray outline pill |
| CONFIRMED | white outline pill |
| SOFT HOLD | white outline pill |
| FAILED | magenta FILLED pill |
| SCHEDULED | cyan filled pill + left dot indicator |
| PUBLISHED | gray filled pill + checkmark icon |
| AWAITING DEPOSIT | magenta filled pill |
| PAID FULL | gray left bar + text (not a pill) |
| SETTLED | gray left bar + text |
| PENDING | magenta text (no pill) |
| NOMINAL | cyan filled pill (system status) |

### List Item Accent Bars
- Every list/table row with status gets a **3–4px left vertical bar** in the status color
- Colors: cyan=ready/confirmed, violet/magenta=draft/pending, yellow=archived/warning
- Bars appear in: tracklist list, recent tracklists widget, gig table rows

### Typography Patterns (concrete)
- **Page/section titles**: mixed weight — light prefix + bold keyword: "Post **Queue**", "Active **Gigs**"
- **Section labels**: ALL_CAPS with underscores: `VISUAL_CONFIGURATION`, `SYSTEM_PROCESS:`, `ACTIVE_TEMPLATE`, `REALTIME_OUTPUT_PREVIEW`
- **Hero headlines**: display font, mixed italic + bold: "CYBER *VOID* MAINSTAGE"
- **Metadata/data labels**: small caps or uppercase, letter-spaced: "REF: KG-8829", "FRI, 24 OCT // 23:00 - 04:00"
- **Monospace data**: latency (1.2ms), speed (982 MB/s), BPM values use tabular data feel

### Progress Bars
- **Height**: 4px thin bar
- **Track**: surface-container-high background
- **Fill**: cyan gradient
- **Label pattern**: `SYSTEM_PROCESS: TRACKLIST_IMPORT_V2` above-left + `84%` right-aligned on same row

### Upload Drop Zone
- Dashed border (NOT solid) — the "ghost border" pattern applied to functional zones
- Icon (cloud upload) in cyan center
- Two-line label: `DROP .XML OR .TXT` bold + `MAX_PAYLOAD: 50MB` subdued beneath
- No background fill — transparent

### Toggle Switches
- 0px border-radius (sharp, matching global rule)
- On: cyan fill + white thumb
- Off: surface-container fill + dim thumb
- Small size (~32×16px)

### Timeline / Date Strip
- Horizontal scrollable strip of `DD / DAY` date cells
- Selected cell: cyan outline box (the dashed/luminous threshold border)
- Event indicator: small colored dot BELOW the date number
- Navigation chevrons (< >) top-right

### Empty State Cards
- Dashed border box (same ghost-border pattern)
- Center icon (gray)
- Bold label: "NEXT SLOT"
- Subdued datetime below

### Table Row States
- Default: transparent background
- Selected/highlighted: subtle **violet/purple background glow** (not a solid fill — translucent surface_variant + secondary at ~15% opacity)
- Date column for upcoming events: **cyan text** (primary color)
- Actions column: three-dot `⋮` menu icon (right-aligned)

### Hero Card Pattern (Dashboard featured gig)
- Left: **4px cyan accent bar** (the luminous threshold — solid here, not dashed)
- Top: small badge tag ("UPCOMING PRIORITY") + reference number ("REF: KG-8829")
- Headline: large display type, italic+bold mix
- Below headline: two metadata columns with label + value
- Right: status block (CONTRACT STATUS label + large bold colored value + CTA button)

### Bottom Status Bar (Dashboard)
- Row of system stats: icon + "HARDWARE INTERFACE" label + key-value pairs
- Values in large monospace-feel display: "1.2ms", "982 MB/s"
- Label above value: small uppercase subdued label

### Color-Coded Chroma Swatches
- Square swatches (0px radius) for color preset picker
- Colors: light blue, magenta, yellow-green, white + add button

### Realtime Preview Panel
- "REALTIME_OUTPUT_PREVIEW" uppercase label top-left
- "● LIVE_RENDER" with red dot top-right
- Phone frame mockup (dark rounded device shell) containing image preview
- Panel background: surface-container (NOT glass — opaque)
