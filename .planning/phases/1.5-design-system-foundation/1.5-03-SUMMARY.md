## Decisions Made

- **PRESETS vs CSS tokens separation:** design-tokens.ts holds image-generation preset colors only. UI theme tokens (--color-primary, etc.) live in styles.css. No overlap prevents confusion between render output colors and app UI colors.
- **Setup store style:** All three stores use Pinia's composition API (setup function) style, not the options API style. Matches the Vue 3 Composition API conventions used elsewhere.
- **abortController is private:** The abortController ref in useTracklistStore is not returned from the store — it's an internal implementation detail for cancellable upload/fetch operations.
