## Decisions Made

- Used `withDefaults(defineProps<Props>())` TypeScript generics style in TrackcardPreview.vue instead of the runtime props object — enables the 60-line target by compressing the interface definition. The sub-components still use runtime props style for compatibility.
- Colors computed once in the orchestrator and passed down as a prop to sub-components that need it (TrackCardTrackRow, TrackCardTrackList, TrackCardFooter), avoiding re-importing PRESETS in multiple places.
- TrackcardPreviewPanel.vue uses `bg-surface-container` (opaque) per the mockup spec override, not `glass-panel` — the preview panel needs a solid background to frame the card correctly.
- Created `apps/dj/app/types/tracklist.ts` as a proper source file — it existed only in dist/ before, which means typecheck targets would fail without it.
