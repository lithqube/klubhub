## Decisions Made

- **Progress simulation:** Upload/export progress bars use fake increment timers since the API has no streaming. Upload increments 0..85% over intervals then jumps to 100% on success. Export uses indeterminate (pulse) animation.
- **Inline editing:** Clicking a table cell activates an Input in-place. blur or Enter commits; Escape cancels. No separate edit mode or modal.
- **Instant settings save:** TracklistCustomizer calls PUT /api/v1/settings on every toggle/select change — no explicit Save button. This matches the original tracklist.vue behavior.
