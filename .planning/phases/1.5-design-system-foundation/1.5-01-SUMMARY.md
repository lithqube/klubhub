## Decisions Made
- Used `@tailwindcss/vite` Vite plugin instead of `@nuxtjs/tailwindcss` module — Tailwind v4 recommends Vite plugin approach; CSS pipeline works even when TypeScript type-check fails
- All design tokens in `@theme` CSS block only — Tailwind v4 CSS-only configuration, no `tailwind.config.ts` file created
- Fonts downloaded directly from GitHub source repos into `public/fonts/` (not npm packages) — avoids CDN dependency and keeps font files in version control
- All `--radius-*` tokens set to `0px` — enforces no rounded corners everywhere in the Cyberpunk HUD aesthetic
- `nav-item-active` uses dashed border all 4 sides per mockup — not left-only or solid fill

## Deviations from Plan

None — plan executed exactly as written.

One observation: pre-existing TypeScript errors in `tracklist.vue` (TS2307, TS2339, TS18046, etc.) cause the full `nuxt build` to fail. These are out of scope for this plan. The Vite CSS pipeline was verified working (178 modules transformed successfully). These errors should be addressed in a separate plan.

## Issues Encountered
- curl URL glob expansion: `curl -L` treated `[slnt,wght]` in font URL as a range. Fixed with `-g` (--globoff) flag — `curl -L -g -o`.
- Pre-existing TypeScript build failures in `tracklist.vue` prevent `pnpm nx build @dev/dj` from exiting 0. Vite/CSS stage verified working independently.
