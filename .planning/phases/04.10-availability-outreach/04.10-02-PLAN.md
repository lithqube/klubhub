<objective>
Build the DJ→promoter backend: availability slots, city matching against the DJ's own promoter contacts, customizable outreach templates, and sending a booking-request email via the shared email platform with an optional EPK PDF attached. Every send is logged and linked to the email outbox; suppressions and a daily cap are enforced.

Output: migrations 033–035, the `api/internal/outreach` package, routes at `/api/v1/outreach`, wired into the DJ binary.
</objective>

- MatchSlots(ctx) — per slot: contacts WHERE type='promoter' AND lower(trim(city))=lower(trim(slot.city)) AND deleted_at IS NULL, excluding suppressed emails; venues in the same city as context; rank: past gig in that city first (join gigs on lower(city)), then name. - RenderTemplate(ctx, template, vars) — email.Render on subject+body.
- variable map builder: dj_* from settings (user_settings via existing settings repo — reuse the settings package read path), promoter_* from contact, city/date/genres/fee/notes from slot, epk_link from config EPK_PUBLIC_URL.
- SendRequest(ctx, req) — the core:
  1. Load contact (must exist, type='promoter', not deleted); refuse if normalized email ∈ suppressions (ErrSuppressed).
  2. Daily limit: count outreach_requests created today (or email_messages kind=booking_request) ≥ maxPerDay → refuse (ErrRateLimited).
  3. Resolve template (req.TemplateID or the default) → render subject/body; req.Subject/Body override when non-nil.
  4. If req.EPKExportID != nil: load epk_exports row; upsert documents pointer (owner_type='epk', owner_id=exportID, kind='epk_pdf', storage_key=garage_object_key, filename, mime_type='application/pdf', size_bytes, checksum_sha256, is_current=true) — reuse existing current row if present (ON CONFLICT DO NOTHING + re-select, or GetCurrent first).
  5. Insert outreach_requests row (status='queued') FIRST so the request id exists.
  6. Build email.CreateEmailRequest{Kind: booking_request, FromEmail/FromName from config, ToEmail: contact.Email, Subject, Body, ReplyTo: dj email}:
     - with EPK: OwnerType='epk', OwnerID=exportID, AttachmentIDs=[docID] → emailSvc.SendOwned
     - without EPK: OwnerType=OwnerTypeOutreachRequest, OwnerID=requestID → emailSvc.Send
  7. Update the request row: email_message_id, status, sent_at (sync from the returned EmailMessage).
- Suppress(ctx, email, reason) / Unsuppress(ctx, id) / IsSuppressed.
