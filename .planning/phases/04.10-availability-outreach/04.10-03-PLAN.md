<objective>
Build the promoter→DJ backend: talent contacts (sealed PII, the DJs the promoter knows), open slots on events, city+genre matching, customizable offer templates, and sending a booking-offer email via the shared email platform. Tenant-scoped end to end, with suppressions (blind-indexed) and a per-tenant daily cap.

Output: migrations 00014–00017, the `api/internal/promoter/bookings` package, Plunk config + per-tenant email worker in the promoter binary, routes at `/api/v1/bookings/*` behind the existing `booking.*` authz actions.
</objective>

**00014_email_messages.sql** — tenant-scoped mirror of platform 017_email.sql: same columns + `tenant_id UUID NOT NULL REFERENCES organizations(id) ON DELETE CASCADE` + indexes (kind, status, (owner_type, owner_id), tenant_id). data_class: internal (delivery metadata; to_email is NOT here — it lives sealed on outreach_requests).

**00015_talent_contacts.sql** — SPEC §6.1: id, tenant_id, name_enc/email_enc/phone_enc BYTEA, name_bidx/email_bidx BYTEA, city TEXT default '', country TEXT default '', genres TEXT[] default '{}', source CHECK IN ('past_gig','referral','manual'), notes, created_at, updated_at; CHECK (email_enc IS NOT NULL OR name_enc IS NOT NULL); UNIQUE INDEX (tenant_id, email_bidx) WHERE email_bidx IS NOT NULL; index (tenant_id, lower(city)); GIN index on genres if the matcher needs it (or filter in SQL with &&). Comments: name/email/phone = personal; city/country/genres/source = internal matching keys.

**00016_event_open_slots.sql** — SPEC §6.1: id, tenant_id, event_id REFERENCES events(id) ON DELETE CASCADE, role TEXT default '', genres TEXT[] default '{}', fee_min/fee_max NUMERIC(12,2), currency CHAR(3), notes, created_at, UNIQUE(event_id, role); index (tenant_id, event_id).

**00017_outreach.sql** — three tables:
- outreach_templates: id, tenant_id, direction CHECK IN ('promoter_to_dj'), name, subject, body, is_default, created_at, updated_at, deleted_at; unique partial index one-default per (tenant_id, direction); seed the default promoter_to_dj template (SPEC §7: event name/date/city/venue, slot role/genres/fee, org identity, opt-out footer).
- outreach_requests: id, tenant_id, event_id REFERENCES events(id) ON DELETE SET NULL, open_slot_id REFERENCES event_open_slots(id) ON DELETE SET NULL, talent_contact_id REFERENCES talent_contacts(id), template_id REFERENCES outreach_templates(id) ON DELETE SET NULL, email_message_id REFERENCES email_messages(id) ON DELETE SET NULL, to_email_enc BYTEA (sealed), to_email_bidx BYTEA, subject, body, status CHECK IN ('queued','sending','sent','failed','bounced'), sent_at, created_at; indexes (tenant_id, talent_contact_id), (tenant_id, created_at).
- outreach_suppressions: id, tenant_id, email_bidx BYTEA NOT NULL, reason, created_at, UNIQUE (tenant_id, email_bidx). The email itself is NEVER stored here.
