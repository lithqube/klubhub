# Decoupling points
- AttachmentSource currently returns *finance.Document. Re-type it over a minimal AttachmentDoc {ID, OwnerType, OwnerID, Filename, MimeType} defined in platform/email. docstore.Document converts to AttachmentDoc; docstore.DocumentService gets GetAttachment/DownloadAttachment methods (or a small adapter type in docstore) satisfying email.AttachmentSource. checkAttachmentOwner compares OwnerType/OwnerID strings — unchanged semantics.
- Kind registry: platform/email owns `type EmailKind string`, a package-level registry with `RegisterKind(EmailKind)` and `IsValid()`. finance registers its six kinds in init(). 04.10-02/03 register booking_request/booking_offer in their packages' init(). validEmailKinds map is replaced by the registry.
- Render: `func Render(text string, vars map[string]string) string` — replaces `{{key}}` occurrences via strings.NewReplacer; unknown keys render empty. **v2.1 hardening (SPEC §7):** values are untrusted (contact names, notes) — `Render` strips CR/LF from every substituted value before replacement (header-injection defense for the subject). v1 sends `text/plain` only; any future HTML variant must HTML-escape values. Shared by both outreach directions.
- FieldCodec (SPEC §6.1/§6.8, v2.1): the promoter outbox must not store talent PII in plaintext, so the shared service seals on write and unseals for delivery/log through a codec:
  ```go
  // codec.go (platform/email)
  type FieldRef struct { Table, Column string; RowID uuid.UUID }
  type FieldCodec interface {
    Seal(ctx context.Context, tx pgx.Tx, f FieldRef, plaintext string) ([]byte, error)
    SealEmail(ctx context.Context, tx pgx.Tx, f FieldRef, email string) (enc, bidx []byte, err error)
    Open(ctx context.Context, tx pgx.Tx, f FieldRef, sealed []byte) (string, error)
  }
  type IdentityCodec struct{} // passthrough: Seal returns []byte(plaintext), Open returns string(sealed)
  ```
  `EmailService` gains a codec (constructor option / `WithFieldCodec`; nil = IdentityCodec). On the enqueue path the service seals `to_email` (+ blind index), `subject`, `body`, `body_html`, `reply_to` when the codec is envelope-backed; on the delivery path (worker claim / `loadMessage`) and the status/log read path it unseals before handing values to the sender or handler. The envelope-backed implementation lives on the promoter side (`api/internal/promoter/bookings/codec.go` — `EnvelopeCodec{Keys *envelope.Keyring}`, resolves the tenant from ctx inside `WithTenant`, `keys.Current(ctx, tx, tenant)`, maps `FieldRef` → `envelope.Field{Table, Column, RowID}`, `dek.BlindIndex(table, col, envelope.NormalizeEmail(email))`) so platform/email stays free of envelope/keys imports. platform/email defines its own `FieldRef` (no envelope import).
- Tenant scoping (for 04.10-03): `NewEmailRepository(db *tenantdb.DB, tenantScoped bool)` — **takes `*tenantdb.DB`, not a raw pool** (SPEC §6.8: keeps the `internal/promoter` pool-import guard meaningful). The DJ side wraps its pool: `tenantdb.New(pool)` (cmd/api has no tenantdb today — `tenantdb.New` is a thin wrapper, `tenantdb.go:90`). When true, INSERT populates `tenant_id` from `tenantdb.TenantFromContext(ctx)` and every statement runs inside `db.WithTenant` (RLS FORCE isolates). When false (DJ side), SQL is byte-identical to today (plaintext columns). The tenant-scoped variant's SQL writes the sealed columns (`to_email_enc`, `to_email_bidx`, `subject_enc`, `body_enc`, `body_html_enc`, `reply_to_enc` — no cc/bcc) and reads them back as BYTEA for the service to unseal.

     func Render(text string, vars map[string]string) string {
       if len(vars) == 0 { return text }
       pairs := make([]string, 0, len(vars)*2)
       for k, v := range vars {
         v = strings.NewReplacer("\r", " ", "\n", " ").Replace(v)

     }
