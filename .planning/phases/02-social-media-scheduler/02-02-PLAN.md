<objective>
Build the Instagram Graph API HTTP client and the Go background publishing worker. The worker polls the database every 60 seconds, publishes due posts via the two-step Instagram API flow, handles retries with exponential backoff, enforces rate limits, and refreshes expiring OAuth tokens.

Purpose: This is the core autonomous reliability layer — the worker is what makes "schedule once, publish reliably" real. It must handle all failure modes: retries, rate limits, duplicate prevention, and token expiry.
Output: instagram.go (API client), worker.go (ticker goroutine), registered in main.go.

func StartPublishWorker(ctx context.Context, svc *Service, log zerolog.Logger) {
    ticker := time.NewTicker(60 * time.Second)
    defer ticker.Stop()
    for {
        select {
        case <-ticker.C:
            svc.PublishDuePosts(ctx)
            svc.RefreshExpiringTokens(ctx)
        case <-ctx.Done():
            return
        }
    }
}

  <behavior>
    - Worker tick calls ListDuePosts and attempts to publish each; posts not yet at scheduled_at_utc are skipped
    - Publish flow: update status→publishing, generate presigned URL, create container, publish container, update status→published
    - On publish failure: increment retry_count, set next_retry_at per backoff, update status→failed; last_error stores the error message
    - On retry_count already at 3 before attempt: mark permanently_failed (do not attempt)
    - Before retrying (retry_count > 0): call CheckContainerStatus; if PUBLISHED, mark published locally without re-publishing
    - Worker enforces 30-second minimum between Instagram API calls using a lastPublishedAt tracker
    - On RateLimitError: set next_retry_at = now + RetryAfter; skip remaining due posts for this tick
    - Token refresh: for each account in ListExpiringAccounts, call instagram.RefreshToken; on success update token + expiry; on failure mark account disconnected
    - Worker goroutine exits cleanly when ctx is cancelled
  </behavior>
  <action>
    **worker.go**: Define `Worker` struct with `svc serviceIface`, `repo *Repository`, `instagram *InstagramClient`, `storage storageIface` (for presigned URLs), `cryptoKey []byte`, `log zerolog.Logger`.

    Implement `func StartPublishWorker(ctx context.Context, w *Worker)` as a goroutine with `time.NewTicker(60 * time.Second)`.

    Core method `func (w *Worker) tick(ctx context.Context) error`:
    1. Call `w.repo.ListDuePosts(ctx)` to get posts with scheduled_at_utc <= now AND (next_retry_at IS NULL OR next_retry_at <= now)
    2. For each post, check rate limit (30s since last publish)
    3. If retry_count >= 3: call `w.repo.UpdatePostStatus(ctx, id, PostStatusPermanentlyFailed, "max retries exhausted")` and continue
    4. If retry_count > 0 AND post has container_id: call `w.instagram.CheckContainerStatus`; if PUBLISHED, mark published and continue
    5. Mark post as publishing: `w.repo.UpdatePostStatus(ctx, id, PostStatusPublishing, "")`
    6. Decrypt access token: `platform/crypto.Decrypt(w.cryptoKey, account.AccessToken)`
    7. Generate presigned URL via storage interface (30-minute expiry)
    8. If image is PNG (detect via mimetype package): convert to JPEG in memory
    9. Call `w.instagram.CreateContainer(ctx, account.IgUserID, token, presignedURL, post.Caption, post.PostType)`
    10. On RateLimitError: call `w.repo.SetNextRetry(ctx, id, post.RetryCount+1, now+rateLimitError.RetryAfter)` and stop processing remaining posts for this tick
    11. Store containerID: `w.repo.UpdateContainerID(ctx, id, containerID)` (add this method to repository)
    12. Call `w.instagram.PublishContainer(ctx, account.IgUserID, token, containerID)`
    13. On success: `w.repo.UpdatePostStatus(ctx, id, PostStatusPublished, "")`; record lastPublishedAt = now
    14. On any error: `w.repo.SetNextRetry(ctx, id, post.RetryCount+1, backoffTime(post.RetryCount))`; `w.repo.UpdatePostStatus(ctx, id, PostStatusFailed, err.Error())`

    Backoff helper: `func backoffTime(retryCount int) time.Time` — returns now + [5, 20, 80][retryCount] minutes.

    Token refresh method `func (w *Worker) refreshExpiringTokens(ctx context.Context)` — calls `w.repo.ListExpiringAccounts(ctx)`, for each decrypts token, calls `w.instagram.RefreshToken`, on success re-encrypts and updates DB, on failure marks account disconnected.

    **main.go**: Wire up `Worker` with the social service, repo, instagram client, storage, and crypto key. Call `go social.StartPublishWorker(ctx, worker)` after app startup. Ensure worker goroutine is captured by context cancellation on SIGTERM (existing graceful shutdown pattern).

    **worker_test.go**: Test `tick` with mocked repo and instagram client. Test that retry_count=3 marks permanently_failed without calling InstagramClient. Test backoffTime returns correct durations. Test RateLimitError stops processing remaining posts for the tick.
