    - POST /api/v1/social/posts (feed image upload) returns 422 when aspect ratio is outside 4:5–1.91:1 range
    - POST /api/v1/social/posts (feed image upload) returns 422 when image is below 320×320 px minimum
    - POST /api/v1/social/posts (story image upload) returns 422 when aspect ratio is not 9:16 (tolerance ±0.05)
    - POST /api/v1/social/posts/{id}/retry resets post status to 'scheduled' and sets next_retry_at to now; returns 200
  </behavior>
  <action>
    **service.go**: Define `serviceIface` interface consumed by handler. Implement `Service` struct with repo and crypto key. Key methods:
    - `GetOAuthURL(ctx) (string, error)` — build Instagram OAuth URL: `https://api.instagram.com/oauth/authorize?client_id={APP_ID}&redirect_uri={REDIRECT_URI}&scope=instagram_business_basic,instagram_business_content_publish&response_type=code&state={uuid}`. Read INSTAGRAM_APP_ID and INSTAGRAM_REDIRECT_URI from config/env.
    - `HandleOAuthCallback(ctx, code, state string) (*SocialAccount, error)` — exchange code for short-lived token via `POST https://api.instagram.com/oauth/access_token`, then exchange for long-lived token via `GET https://graph.instagram.com/access_token`, encrypt with platform/crypto, store in DB
    - `SchedulePost(ctx, req CreatePostRequest) (*ScheduledPost, error)` — parse datetime-local + timezone → UTC using `time.LoadLocation` + `time.ParseInLocation`; validate image if custom upload; store in repository
    - `EditPost(ctx, id UUID, req EditPostRequest) (*ScheduledPost, error)` — return ErrEditBlocked if post status != 'scheduled'
    - `DisconnectAccount(ctx, id UUID) error` — calls repo.DisconnectAccountCascade then repo.UpdateAccountStatus
    - `RetryPost(ctx, id UUID) error` — calls repo.ResetPostForRetry; returns ErrNotFound if post does not exist
    - `ValidateImage(data []byte, postType PostType) error` — performs three checks in order:
      1. MIME type: must be JPEG or PNG (use gabriel-vasile/mimetype); return ErrInvalidMIME on violation
      2. File size: len(data) must be ≤ 8*1024*1024; return ErrFileTooLarge on violation
      3. Dimensions and aspect ratio: decode image header using `image.DecodeConfig` (stdlib, no full decode needed) to get width/height without loading full pixel data:
         - Feed (PostTypeFeed): width ≥ 320, height ≥ 320; ratio = float64(width)/float64(height) must be in [0.8, 1.91]; return ErrInvalidDimensions on violation
         - Story (PostTypeStory): ratio must be within ±0.05 of 0.5625 (9:16); return ErrInvalidDimensions on violation
         Note: `image.DecodeConfig` requires registering decoders — import `_ "image/jpeg"` and `_ "image/png"` as blank imports.

    **handler.go**: `Handler` struct with `svc serviceIface`. Register routes in `Routes()` func:
    - `GET /auth/url` → GetOAuthURL
    - `POST /auth/callback` → HandleOAuthCallback (reads `code` + `state` from query params for GET redirect, or JSON body for POST)
    - `GET /accounts` → GetAccount (returns 200 with null data if no account)
    - `DELETE /accounts/{id}` → DisconnectAccount
    - `GET /posts` → ListPosts
    - `POST /posts` → SchedulePost (multipart/form-data: caption, post_type, scheduled_at, timezone_name, image_id (existing MinIO path) or image_file (upload))
    - `GET /posts/{id}` → GetPost
    - `PUT /posts/{id}` → EditPost
    - `DELETE /posts/{id}` → SoftDeletePost
    - `POST /posts/{id}/retry` → RetryPost (returns 200 with updated post JSON; 404 if not found)

    Register handler in main.go/router under `/api/v1/social`.
