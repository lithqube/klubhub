Make two targeted edits to api/internal/social/worker.go:

**Edit 1 — Remove convertPNGToJPEG from instagramIface (lines 33-39):**

The `instagramIface` currently declares `convertPNGToJPEG(pngData []byte) ([]byte, error)`. This is an unexported method name — Go does not allow unexported methods in interface definitions in the same package in a meaningful way (the concrete type satisfies it, but it cannot be satisfied by an external mock). Remove this line from the interface. The interface should only contain exported methods: CreateContainer, PublishContainer, CheckContainerStatus, RefreshToken.

**Edit 2 — Replace dead code block at processPost step 8 (lines 185-191):**

Replace:
```go
// 8. Detect if image is PNG and convert to JPEG.
imageURL := presignedURL
_ = imageURL // we pass presignedURL directly; PNG conversion happens at the byte level if needed
// Note: Since we pass a URL (not raw bytes) to Instagram, PNG→JPEG conversion is only
// relevant when we have the actual image bytes. The presigned URL scenario passes the URL
// directly to Instagram's servers. PNG conversion is available via convertPNGToJPEG for
// direct byte upload scenarios. For URL-based uploads, Instagram accepts PNG transparently.
```

With:
```go
// 8. Pass the presigned URL to Instagram.
// Instagram Graph API accepts both JPEG and PNG via URL-based container creation.

// needed here: the API server downloads the image directly from the presigned URL.
```


The `imageURL` variable and `_ = imageURL` line are removed entirely.
